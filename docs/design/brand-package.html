GunWall — Null Cell
A 4×4 modular grid — the firewall as a built surface. Fifteen cells are filled. One is held blank: the data the system never holds. One is red: the packet under inspection.
Zero Trust reads in the red cell — every unit is examined, none is assumed. Zero Knowledge reads in the outlined void — the wall stands complete around something it cannot see.
Geometry only: no gradients, no radius, no bevels. The mark is legible at 16px and reproduces in a single ink.
