# Screenshots

Captures used in the project README. Refresh them when the interface changes
materially — a stale screenshot is a small dishonesty.

| File | Screen | Theme |
|---|---|---|
| `dashboard-dark.png` / `dashboard-light.png` | Overview | both |
| `traffic-dark.png` / `traffic-light.png` | Traffic | both |
| `security-dark.png` | Security & Privacy | dark |
| `settings-dark.png` | Settings | dark |
| `activity-light.png` | Activity | light |

**Capturing.** Full window, 1400 px wide or larger, on a machine with real
traffic — an empty dashboard sells nothing. Avoid anything identifying: local
addresses are fine, but check the process list and any host names before
publishing.

The dashboard pair is served through a `<picture>` element so the README shows
whichever matches the reader's theme.
